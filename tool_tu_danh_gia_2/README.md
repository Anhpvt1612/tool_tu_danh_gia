# Viettel Post Auto Rate

Extension Chrome Manifest V3 hỗ trợ đánh giá 5 sao các đơn hàng đang có trong trang “Đơn hàng gửi” của Viettel Post.

## Cài đặt

1. Mở `chrome://extensions` và bật **Developer mode**.
2. Chọn **Load unpacked** và chọn thư mục này.
3. Mở Viettel Post, vào **Đơn hàng gửi**, sau đó bấm biểu tượng extension.
4. Bấm **Bắt đầu**. Có thể bấm **Dừng** để dừng sau thao tác hiện tại.

Extension chỉ thao tác các phần tử giao diện đang có trên trang; không gọi API riêng và không lưu thông tin đăng nhập.
